# Project Navya - Youth Ambassador Program

Project Navya is a student-led youth ambassador program focused on learning, awareness, respectful fundraising, and meaningful impact through the Children of the Mother Soil initiative.

The website introduces the purpose of Project Navya, explains the Youth Ambassador Internship, provides an application form for interested interns, highlights top youth ambassadors, and includes information for students who want to join the Project Navya team.

## Website Sections

### Home
The Home page introduces Project Navya and explains the issue of food insecurity. It also gives visitors quick access to the internship page and donation page.

### About
The About page explains why Project Navya was created, the motive behind the program, and introduces the founder, Nishtha Desai.

### Internship
The Internship page explains what youth ambassadors will do, how interns can fundraise, the benefits of participating, the top youth ambassador leaderboard, and the internship application form.

### Join Our Team
The Join Our Team page shares open Project Navya team positions. Currently, Project Navya is accepting interest for the Social Media Manager Team. Students interested in this role are asked to send their resume to the Project Navya email listed on the Contact page.

### Donate
The Donate page provides information about supporting the Children of the Mother Soil initiative through the approved donation method.

### Contact
The Contact page includes program contact information, Google Classroom details, and frequently asked questions.

## Features

- Multi-page style website using HTML, CSS, and JavaScript
- Navigation tabs for Home, About, Internship, Join Our Team, Donate, and Contact
- Embedded Google Form for intern applications
- Top Youth Ambassador leaderboard
- Impact statistics section
- Responsive design for desktop and mobile
- Organized sections for program information, applications, team roles, and FAQs
